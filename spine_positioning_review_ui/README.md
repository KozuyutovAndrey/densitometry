# Spine Iliac Review UI

Временный UI для ручной проверки наличия подвздошных костей на оригинальных снимках позвоночника.

Запуск:

```bash
uv run python spine_positioning_review_ui/server.py --host 0.0.0.0 --port 8771
```

Открыть с этой машины:

```text
http://127.0.0.1:8771
```

Открыть из локальной сети/Tailscale:

```text
http://<ip-сервера>:8771
```

Что размечается:

- `Подвздошные кости видны` — нижняя часть spine-снимка захвачена корректно.
- `Подвздошные кости не видны` — укладка/захват снизу некорректны.
- `Сомнительно` — спорный случай для отдельного разбора.

Дефолтная метка берется из текущего датасета `artifacts/spine_positioning_dataset/annotations.csv`. UI показывает и оригинальные снимки, и synthetic bottom-crop аугментации; для них есть отдельные фильтры `Оригиналы` и `Синтетика`.

Дополнительно можно отметить, использовать ли конкретный снимок в обучении классификатора. Это отдельный флаг и он не меняет медицинскую метку видимости подвздошных костей.

Результат сохраняется в:

```text
artifacts/spine_positioning_dataset/manual_iliac_review.csv
```

Горячие клавиши:

- `1` — подвздошные кости видны;
- `0` — подвздошные кости не видны;
- `?` — сомнительно;
- `T` — использовать в обучении;
- `E` — не использовать в обучении;

Клавиши `T/E` обрабатываются по физической клавиатуре, поэтому работают и при русской раскладке.
- `S` — сохранить;
- `←` / `→` — навигация.
